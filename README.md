# Game Theory

Studies about game theory

## Tic Tac Toe Solver
Solves [Tic Tac Toe](https://en.wikipedia.org/wiki/Tic-tac-toe) game for a certain starting player and board.

**That is**: If both players play optimally in a given state, what should be the outcome.

Uses [Minimax](https://en.wikipedia.org/wiki/Minimax) algorithm to consider optimal play for both players.
